name: code-review
description: Review code for quality and issues
---

Review the provided code for:
1. Security issues (SQL injection, XSS, auth bypass)
2. Code quality (god code, duplication, complexity)
3. Type safety (missing types, any usage)
4. Error handling (swallowed errors, missing validation)
5. Performance (N+1 queries, unnecessary re-renders)
6. Adherence to project rules (max 200 lines, service layer, etc.)

Provide specific line-by-line feedback and suggestions.
